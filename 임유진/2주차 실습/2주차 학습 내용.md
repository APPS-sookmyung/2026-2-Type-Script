# TypeScript 기본 타입

## 10. 기본 타입

```ts
let age: number = 25;
age = 26;

const firstName: string = "Alice";
firstName = "Bob"; // ❌

var isOld: boolean = false; // ⚠️
```

- 위 코드에서 `firstName`은 상수이기 때문에 값을 변경할 수 없음
- `var`는 스코프 관련 문제를 갖고 있기 때문에 권장X
- 변수는 선언만 해두었다가 추후에 값을 할당하는 것도 가능
- 변수의 자료형을 제한할 수 있음

```ts
let score;

score = 95;
score = "95";
```

- 위의 경우 `score`의 타입은 any로 지정됨
- any: 어떤 값이든 허용하는 가장 느슨한 타입
- JS와 마찬가지로 `0x`, `0b`, `0o`를 사용해 각각 16진법, 2진법, 8진법으로 수를 나타낼 수 있음

## 11. any, unknown 형

### any

- 변수의 자료형 지정 가능 (`let anyValue: any = 10;`)
- 어떤 자료형이 와도 상관없지만, 이는 TS를 사용하는 의미가 없게 하므로 지양해야 할 코드
- 해당 값에 어떤 속성이나 메소드가 있는지 전혀 확인되지 않음
- 타입 안정성보다 빠른 개발과 임시 테스트가 필요한 경우에 제한적으로 사용됨

### unknown

- 타입을 미리 알 수 없는 값에 대해 안전하게 다룰 수 있도록 대부분의 연산을 제한
- 모든 타입 경우에 대한 코드가 필요함 (타입 가드)
- 타입 검사를 필수로 요구하기 때문에 안정성이 요구되는 곳에서 `any`보다 더 권장됨

  ```ts
  function processValue(val: unknown): string {
    if (typeof val === "string") {
      return val.toUpperCase(); // ✅
    }

    if (typeof val === "number") {
      return val.toFixed(2); // ✅
    }

    return String(val);
  }
  ```

```ts
function processUserData(user: unknown): string {
  // Type guard for object
  if (typeof user === "object" && user !== null) {
    if ("name" in user && typeof (user as any).name === "string") {
      return `User: ${(user as any).name}`;
    }
  }
  return "Invalid user data";
}
```

## 12. null, undefined, void, never

### null

- 값이 의도적으로 비어있음

### undefined

- 변수가 선언되었지만 값이 아직 할당되지 않았거나 정의되지 않은 상태

### void

- 함수나 메소드에서 반환값이 존재하지 않음을 의미하며, 주로 아무것도 반환하지 않는 함수의 리턴 타입으로 사용됨

### never

- 함수가 정상적으로 끝나지 않거나(예: 무한 루프, 항상 예외를 던지는 함수) 절대 발생할 수 없는 타입을 나타낼 때 사용됨

# TypeScript 배열, 튜플, 함수

## 13. 배열과 튜플, 객체 기초

### 배열

- 대괄호를 사용하는 방식과 제네럴을 사용하는 방식은 기능적으로 동일
- 배열은 길이가 유동적이므로 타입만 지정한 뒤 요소 추가도 가능
- `push`를 이용해 배열 끝에 새로운 요소 추가 가능
- 타입스크립트에서는 배열 타입도 추론 가능
- 다차원 배열의 경우 내부의 내부 요소가 달라지면 오류 발생

```ts
const names: string[] = ["Alice", "Bob", "Charlie", "David"];

const nameLengths: number[] = names.map((name) => name.length);
console.log(nameLengths);

const longNames: string[] = names.filter((name) => name.length > 4);
console.log(longNames);

const foundName: string | undefined = names.find((name) =>
  name.startsWith("B"),
);
console.log(foundName);
```

- 배열 요소의 타입에 따라 콜백 함수에 사용되는 타입도 한정됨

#### 읽기 전용 배열

1. 제네릭 타입 이용: 기존의 일반 배열을 할당해서 수정 불가능한 배열로 생성
2. `readonly` 연산자 사용

```ts
const originalArray: number[] = [1, 2, 3, 4, 5];
originalArray[0] = 10; // ✅

const readOnlyNumbers: ReadonlyArray<number> = originalArray;

const readOnlyScores: readonly number[] = [90, 85, 95];
```

### 튜플

- 배열처럼 생겼으나 각 요소의 순서와 타입이 정해져 있음
- 선택적 요소도 포함 가능
  ```ts
  type OptionalTuple = [string, number, boolean?];
  ```
- 함수의 반환 값으로도 사용 가능
  ```ts
  function getUserInfo(): [string, number, boolean] {
    // Returns username, age, and isAdmin status
    return ["alex_dev", 28, false];
  }
  ```

```ts
const inferredArray = [1, "hello"];
// inferredArray: (string | number)[]

const inferredTuple = [1, "hello"] as const;
// inferredTuple: readonly [1, "hello"]
```

## 14. 열거형

- 열거형을 사용해서 의도치 않은 값이 사용되는 걸 방지할 수 있음
- 값을 명시하지 않을 경우 0부터 차례대로 할당됨
- 문자열 타입은 열거형으로 인정되지 않음

  ```ts
  enum Theme {
    Light = "light-theme",
    Dark = "dark-theme",
    System = "system-theme",
  }

  function applyTheme(theme: Theme): void {
    const className = theme;
    console.log(`Theme applied: ${className}`);
  }

  applyTheme(Theme.Dark);
  applyTheme("light-theme"); // ❌

  console.log(Theme.Dark); // "dark-theme"
  console.log(Theme.System); // "system-theme"
  console.log(Theme.Light); // "light-theme"
  ```

- 같은 열거형 내에서 숫자와 문자열 값은 함께 사용될 수 있음
- **열거형**: 값과 이름을 모두 관리하거나 복잡한 로직이 필요한 경우
- **const 열거형**: 객체를 남기고 싶지 않을 때
- **union**: 단순한 고정값 집합을 타입만으로 엄격하게 관리하고 싶을 때

## 15. 함수

- 함수 선언 방식은 아래와 같음

  ```ts
  function greet(name: string): string {
    return `Hello, ${name}!`;
  }

  const farewell = function (name: string): string {
    return `Goodbye, ${name}!`;
  };

  const add = (a: number, b: number): number => {
    return a + b;
  };
  ```

- 선택적 매개변수도 사용 가능

### 함수 오버로딩

```ts
function processInput(value: string): string;
function processInput(value: number): number;

function processInput(value: string | number): string | number {
  if (typeof value === "string") {
    return value.toUpperCase();
  } else {
    return value * 2;
  }
}

console.log(processInput("hello")); // HELLO
console.log(processInput(5)); // 10
console.log(processInput(true)); // ❌
```

1. 문자열을 매개변수로 받아 문자열을 반환하는 버전
2. 숫자를 매개변수로 받아 숫자를 반환하는 버전

### 콜백 함수

```ts
function fetchData(url: string, callback: (data: string) => void): void {
  setTimeout(() => {
    const data = `Data from ${url}`;
    callback(data);
  }, 100);
}

fetchData("api/users", (response) => {
  console.log(response);
});
```

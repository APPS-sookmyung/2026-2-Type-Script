# TypeScript 클래스

## 클래스 1

### 클래스 기본 구조
```ts
class Person {
  name: string;
  age: number;

  // 클래스의 생성자 (인스턴스를 만드는 메소드)
  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }

  describe(): string {
    return `${this.name} is ${this.age} years old.`;
  }
}

const john = new Person('John', 30);

console.log(john.describe());
```

### 접근 제어자
**1. public**
- 어디에서든 접근 가능

**2. private**
- 클래스 외부에서 인스턴스를 통해 해당 값을 사용하려 하면 컴파일 오류 발생
- 해당 클래스 내에서만 사용 가능

**3. protected**
- `public` 보다는 제한되지만 `private`보다는 자유로움
- 해당 클래스로부터 상속받은 클래스 내에서도 사용될 수 있음

### 생성자 단축 문법

```ts
class UserA {
  id: number;
  name: string;

  constructor(id: number, name: string) {
    this.id = id;
    this.name = name;
  }
}

class UserB {
  constructor(public id: number, public name: string) {}
}
```

### 접근 제어자

- `readonly` : 읽기만 가능, 고정된 값을 갖는 속성을 만들기 위해 사용
- `private`을 붙여 접근도 막을 수 있음 
```ts
class Config {
  readonly appName: string;
  version: string = "1.0.0";

  constructor(appName: string) {
    this.appName = appName;
  }

  print() {
    console.log(`${this.appName} v${this.version}`);
  }
}

const cfg = new Config("MyApp");
cfg.version = "2.0.0";
cfg.appName = "Other";  // ❌
```

## 클래스 2

### 상속
- `extends` 키워드를 사용하여 다른 클래스로부터 상속 받음
```ts
class Animal {
  constructor(public name: string) {}

  move(distance: number): void {
    console.log(`${this.name} moved ${distance} meters.`);
  }
}

class Bird extends Animal {
  fly(): void {
    console.log(`${this.name} is flying!`);
  }
}

const sparrow = new Bird("Sparrow");
sparrow.move(10);  // Sparrow moved 10 meters.
sparrow.fly();     // Sparrow is flying!
```
- **오버라이딩**: 부모 클래스에서 정의한 메소드를 자식 클래스에서 재정의하는 것
- **super**
  - 상속받은 자식 클래스에서 부모 클래스의 기능을 재사용할 때 사용
  - 자식 클래스를 만들 때 부모가 가지고 있는 필수 속성을 직접 초기화할 수 없기 때문에 super 사용 
  
 ```ts
class Person {
    constructor(public name: string) {}
    greet(): void {
      console.log(`Hello, my name is ${this.name}.`);
    }
  }

  class Employee extends Person {
    constructor(name: string, public department: string) {
      super(name); 
    }
    greet(): void {
      super.greet(); 
      console.log(`I work in ${this.department}.`);
    }
  }

  const emp = new Employee("Alice", "Engineering");
  emp.greet();
 ```

### 다형성

```ts
class Animal {
  constructor(public name: string) {}

  speak(): void {
    console.log(`${this.name}: (sound)`);
  }
}

class Cat extends Animal {
  speak(): void {
    console.log(`${this.name}: Meow`);
  }
}

class Dog extends Animal {
  speak(): void {
    console.log(`${this.name}: Woof`);
  }
}

const animals: Animal[] = [
  new Cat("Luna"),
  new Dog("Buddy"),
  new Cat("Milo"),
];

for (const animal of animals) {
  animal.speak();
}
```

### 추상 클래스
- `abstract` 키워드 사용
- 추상 클래스로부터 상속받은 자식 클래스드른 해당 메소드를 오버라이드하여 구현해야 함
```ts
abstract class Animal {
  constructor(public name: string) {}

  abstract speak(): void;

  move(): void {
    console.log(`${this.name} moves.`);
  }
}

class Cat extends Animal {
  speak(): void {
    console.log(`${this.name}: Meow`);
  }
}
```

### 클래스에 인터페이스 적용하기

#### 추상 클래스 vs 인터페이스
- **추상 클래스**
  - 추상 메소드가 아닌 일반 메소드도 가질 수 있음
  - 메소드의 구현을 추상 클래스에서 해 놓는 것도 가능
  - 생성자 포함 가능
  - 하나의 부모로부터만 상속 가능
  
- **인터페이스**
  - 메소드를 선언하는 것만 가능
  - 무엇을 하는 메소드인지 작성할 수 없음
  - 생성자 포함 불가능
  - 한 클래스에 여러 인터페이스 상속 가능 (다중 구현)
  - _데이터 구조만 단순하게 표현할 때는 클래스보다 인터페이스(interface)가 훨씬 가볍고 편하기 때문에 데이터 전용 객체에는 인터페이스를 더 자주 사용_
  

### 정적 멤버
- 인스턴스를 만들지 않고도 사용할 수 있는 속성이나 메소드
- `static` 키워드 사용
- 클래스 이름에 바로 마침표를 붙여 속성과 메소드에 접근 가능

```ts
class MathUtil {
  static PI: number = 3.14159;

  static square(x: number): number {
    return x * x;
  }
}

console.log(MathUtil.PI);        // 3.14159
console.log(MathUtil.square(5)); // 25
```

# TypeScript 고급형

## 고급 타입

### 인터섹션 타입

- `&` 을 이용하여 합칠 수 있음
- 서로 다른 타입의 속성을 결합해 더 구체적인 타입을 만들 때 유용
- 모든 속성을 반드시 포함해야 하므로, 속성이 많아질수록 객체를 정의하기 복잡해짐

```ts
type Person = {
  name: string;
  age: number;
};

type Employee = {
  employeeId: number;
  department: string;
};

type Staff = Person & Employee;

const alice: Staff = {
  name: "Alice",
  age: 30,
  employeeId: 101,
  department: "HR",
};
```

### 타입 가드

```ts
type Dog = {
  kind: "dog";
  bark: () => void;
};

type Cat = {
  kind: "cat";
  meow: () => void;
};

type Animal = Dog | Cat;

function makeSound(animal: Animal) {
  if (animal.kind === "dog") {
    animal.bark();
  } else {
    animal.meow();
  }
}
```

### 리터럴 타입

- 열거형에 비해 더 간결하고 유연
- 문자열이나 숫자 같은 기본 타입을 직접 사용해 별도의 선언 없이 값의 범위 제한 가능
- Boolean 타입: 함수를 사용하는 사람이 **의식적으로 `true`를 입력**하도록 하기 위해 사용 가능

```ts
type ButtonSize = "small" | "medium" | "large";

function createButton(size: ButtonSize) {
  console.log(`Button size is: ${size}`);
}

createButton("medium"); // ✅
createButton("extra-large"); // ❌
```

```ts
const mode1 = "light"; // type: "light", 리터럴 타입
let mode2 = "light"; // type: string, 문자열 타입

function setTheme(theme: "light" | "dark") {
  console.log(`Theme set to ${theme}`);
}

setTheme(mode1); // ✅
setTheme(mode2); // ❌
```

```ts
const config = {
  env: "production",
  debug: false,
};

config.debug = true;

const strictConfig = {
  env: "production",
  debug: false,
} as const; //readonly 속성 부여

strictConfig.debug = false; // ❌
```

## 고급형

### 맵드 타입과 인덱스 시그니처의 활용

```ts
type User = {
  id: number;
  name: string;
  email: string;
};

type ReadonlyUser = {
  readonly [K in keyof User]: User[K];
};

const readonlyUser: ReadonlyUser = {
  id: 1,
  name: "John",
  email: "john@example.com",
};

readonlyUser.id = 2; // ❌
```

### 탬플릿 리터럴 타입

- 타입 안정성을 확보하면서 정확한 조합만 허용할 수 있음

```ts
type Lang = "en" | "fr" | "sp";

type Locale = `locale-${Lang}`;
// "locale-en" | "locale-fr" | "locale-sp"

const locale1: Locale = "locale-en";
const locale2: Locale = "locale-fr";
const locale3: Locale = "locale-sp";

const locale4: Locale = "locale-ge"; // ❌
```

```ts
type MultiComb = `${"A" | "B"}-${"on" | "off"}-${1 | 2 | 3}`;
```

#### 사용자 정의 타입 가드

- 복잡한 타입 검사가 여러곳에서 이뤄질 때 유용하게 사용될 수 있음

```ts
type Fish = { swim: () => void };
type Bird = { fly: () => void };

// User-defined Type Guard
function isFish(pet: Fish | Bird): pet is Fish {
  return (pet as Fish).swim !== undefined;
}

function move(animal: Fish | Bird) {
  if (isFish(animal)) {
    animal.swim();
    // animal.fly(); // ❌
  } else {
    animal.fly();
  }
}
```

### 타입 단언

- 타입스크립트에게 근거 없는 확신을 주는 데 사용될 수 있음
- `unknown` 은 타입 가드 없이 어떤 속성에 접근하려 하면 컴파일 오류 발생
- 안전한 코드는 아니기에 잘못 사용하지 않도록 주의해야 함

```ts
function handleData(data: unknown) {
  console.log(data.length); // ❌

  const str = data as string;
  console.log(str.length);
}

function process(value: string | number) {
  const str = value as string;
  console.log(str.toUpperCase());
}

const number = 123 as unknown as string; // 이중 단언
const str = number.toUpperCase(); // ☢️
```

#### Non-null 단언 연산자

- 특정 속성이 `undefined`가 아님을 보증
- `!`를 붙여 해당 값이 `undefined`가 아님을 단언

```ts
type User = {
  name: string;
  age?: number; // Optional
};

function printUserAge(user: User) {
  console.log(user.age.toFixed(1)); // ❌

  console.log(user.age!.toFixed(1));
}

printUserAge({ name: "Alice", age: 25 });
printUserAge({ name: "Bob" }); // ⚠️
```

# TypeScript 제네릭

## 제네릭 기초

### 제네릭

- 함수나 클래스를 작성할 때 특정 타입에 국한되지 않고, 다양한 타입을 유연하게 처리할 수 있게 해주는 강력한 기능
- 타입을 고정하지 않고, 사용하는 시점에 타입을 지정할 수 있게 해줌

```ts
function identity<T>(arg: T): T {
  return arg;
}

const a1 = identity<string>("hello");
const a2 = a1.toUpperCase();

const b1 = identity<number>(123);
const b2 = b1.toFixed(2);
```

- 위 예시에서, `T`는 사용자가 원하는 타입으로 동적으로 설정할 수 있음

```ts
// 제네릭을 적용한 인터페이스
interface Box<T> {
  value: T;
}

const numberBox: Box<number> = { value: 123 };
const stringBox: Box<string> = { value: "hello" };
const booleanBox: Box<boolean> = { value: true };
```

```ts
// 제너릭을 적용한 클래스
class KeyValuePair<K, V> {
  constructor(
    public key: K,
    public value: V,
  ) {}

  print(): void {
    console.log(`Key: ${this.key}, Value: ${this.value}`);
  }
}

const pair = new KeyValuePair<string, number>("age", 30);
pair.print(); // Key: age, Value: 30
```

## 제네릭 제약 조건과 조건부 타입

### 제네릭 제약 조건

- 제네릭이 모든 타입이 아닌 특정 조건을 부합하는 타입만 받을 수 있도록 할 수 있음
- 제네릭도 타입 추론 가능

```ts
interface Named {
  name: string;
}

function greet<T extends Named>(person: T): void {
  console.log("Hello, " + person.name);
}

greet({ name: "Alice", age: 30 });
greet({ age: 30 }); // ❌
```

- `keyof` : 그 뒤에 오는 객체의 키들을 문자열 리터럴 타입으로 반환

```ts
// 해당 키에 매칭되는 값의 타입을 보장하면서 안전하게 가져오는 함수

// 제약 조건: 키 K는 반드시 객체 T가 실제로 가진 키들 중 하나여야 함
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const product = { id: 1, name: "Phone", price: 500 };

const productName = getProperty(product, "name");
console.log(productName); // "Phone"

const error = getProperty(product, "weight"); // ❌
```

```ts
interface HasLength {
  length: number;
}

interface HasName {
  name: string;
}

// length, name 두 속성 다 필요 (누락되면 안됨)
function describe<T extends HasLength & HasName>(value: T): void {
  console.log(`${value.name} has length ${value.length}`);
}

describe({ name: "Box", length: 20, color: "red" });
describe({ name: "Box" }); // ❌
```

### 조건부 타입

- 조건부 타입: 타입 수준에서 조건을 걸어 다른 타입을 선택하도록 만드는 기능
- `infer`
  - 조건부 타입 문법 내에서 특정 타입을 추론하여 변수처럼 사용할 수 있게 해주는 키워드
  - 독립적으로는 사용할 수 없으며, 반드시 조건부 타입의 `extends` 절 내부에서만 사용

```ts
// 조건이 참이라면 추론해둔 반환 타입인 R을, 아니라면 never 타입 반환
// 조건: 타입 T가 어떤 인자들을 받고 무언가를 반환하는 함수 타입인가?
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

type A = MyReturnType<() => string>; // string
type B = MyReturnType<() => number[]>; // number[]
type C = MyReturnType<string>; // never

const a: A = "hello";
const b: B = [1, 2, 3];
const c: C = 123;
```

```ts
// 조건: 타입 T가 어떤 인자들을 받고 무언가를 반환하는 함수 타입인가?
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

// 조건: 타입 T가 함수 타입인가?
type MyParameters<T> = T extends (...args: infer P) => any ? P : never;

function createUser(name: string, age: number) {
  return {
    id: Date.now(),
    name,
    age,
  };
}

// 함수 자체의 타입을 가져옴
type NewUser = MyReturnType<typeof createUser>;
// 함수의 반환 값 형태를 그대로 타입으로 가져와 객체(user)의 구조를 안전하게 정의
const user: NewUser = { id: 1, name: "John", age: 30 };

// createUser 함수의 매개변수들을 튜플 타입인 [string, number]로 추출
type CreateUserParams = MyParameters<typeof createUser>;
const params: CreateUserParams = ["John", 30];
```

## 내장 제네릭 타입과 유틸리티 타입

### 내장 제네릭 타입

- 타입스크립트에서 기본으로 제공하는 제네릭 타입
- `WeakMap` : 담을 쌍의 키가 객체여야 함
- `WeakSet` : 요소로 객체만 담을 수 있음

### 비동기 프로그래밍

- 비동기 프로그래밍: 특정 작업의 완료 여부와 상관없이 다음 코드를 즉시 실행하는 프로그래밍 방식
- `Promise` : 비동기 작업의 최종 완료와 그 결과 값을 나타내는 객체
- `async` : 함수 앞에 붙여 해당 함수를 비동기 함수로 정의하는 키워드
- `await` : `Promise` 객체가 처리될 때까지 비동기 함수의 실행을 일시 정지하고 결과 값을 기다리게 만드는 연산자

```ts
type User = {
  id: number;
  name: string;
};

function fetchUser(id: number): Promise<User> {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve({ id, name: "Alice" });
    }, 1000);
  });
}

async function getUserInfo() {
  const user = await fetchUser(1);
  console.log(user);
}

getUserInfo();
```

### 유틸리티 타입

- `Partial` : 주어진 객체 타입의 모든 속성들을 선택적 속성으로 만들어주는데 사용
- `Required` : 전달된 객체 타입의 속성들을 모두 필수 속성으로 갖는 타입을 만듦
- `Pick` : 제네릭으로 주어진 객체 타입 중 특정 속성들만 포함된 새 타입을 생성
- `Omit` : 첫 번째 제네릭으로 주어진 객체 타입으로부터 그 뒤에 작성된 속성을 제거한 객체 타입을 내보냄
- `Record`: 어떤 정해진 키 집합에 대해 각각의 값을 정해진 타입으로 매핑할 때 사용 가능

```ts
type Role = "admin" | "user" | "guest";

const roleDescriptions: Record<Role, string> = {
  admin: "Administrator",
  user: "Regular User",
  guest: "Guest User",
};

console.log(
  roleDescriptions.admin, // "Administrator"
  roleDescriptions.user, // "Regular User"
  roleDescriptions.guest, // "Guest User"
);
```

- `Exclude` : 제네릭으로 전달하여 값 제거
- `Extract` : 둘 모두에 포함된 타입만 추출하여 새 타입이 생성됨(교집합)
- `NonNullable` : `null`과 `undefined`는 불허하는 타입이 생성됨

```ts
function createUserInfo(name: string, age: number) {
  return {
    name,
    age,
  };
}

// 매개변수를 튜플 타입으로 받아옴
type CreateUserInfoParams = Parameters<typeof createUserInfo>;

// 반환값의 타입 추출
type CreateUserInfoReturn = ReturnType<typeof createUserInfo>;

const cloneUserInfo = (...args: CreateUserInfoParams): CreateUserInfoReturn => {
  const [name, age] = args;
  return { name, age };
};

const user1 = createUserInfo("Alice", 30); // { name: 'Alice', age: 30 }
const user2 = cloneUserInfo("Bob", 25); // { name: 'Bob', age: 25 }
```

- `ConstructParameters` : 주어진 클래스의 매개변수의 타입들을 추출

```ts
class Person {
  constructor(
    public name: string,
    public age: number,
  ) {}
}

type PersonArgs = ConstructorParameters<typeof Person>;

const personArgs: PersonArgs = ["John Doe", 30];

// 스프레드 연산자를 사용하여 객체 생성
const person = new Person(...personArgs);
```
